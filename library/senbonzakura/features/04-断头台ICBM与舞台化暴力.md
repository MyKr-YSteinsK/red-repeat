# 断头台、ICBM 与三次副歌的动作变化

## 同一副歌不等于同一句歌词

第一轮副歌，叙述者在欢宴、钢铁牢笼与断头台之间切换，随即出现用光线枪射穿的动作。后来的副歌保留“千本桜”和“声音传不到”的骨架，却改变一些关键名词、目的地和动作。 [[segment:s009]] [[segment:s011]]

刑台与科幻武器的连接另见： [[segment:s012]] [[segment:s016]]

这里既有历史感的刑罚意象，也有 ICBM、光线枪和闪光弹的现代／科幻语言；它们作为歌词中的不同器物，不能凭名称就推导出固定的现实政治阵营。（C-S02 只支持作者所述的日本、大正浪漫与应援歌意识）[[segment:s004]] [[segment:s027]]

## 从俯视、发射到跳离

比较这四句时，真正有助于唱准的是动词：一处在断头台上“俯视”，一处用光线枪“射穿”，一处是把闪光弹“发射升空”，最终还出现“从断头台跳下”与“让光线枪不停开火”。这些是不同的 Segment，不因它们出现在相近的副歌位置就自动合并。 [[segment:s012]] [[segment:s016]]

## 快速定位时不要把两个 ID 混为一谈

现有 source 中，「千本桜」副歌开头复用 s009，多次出现；而后半句的不同武器／动作分别使用 s016、s027、s028、s030 等独立 Segment。Practice 跳转遵守各自 Occurrence；不能从某一处相似旋律猜测“所有重复都该用相同的歌词”，也无需擅改已有 Timeline。 [[segment:s009]] [[segment:s016]]
