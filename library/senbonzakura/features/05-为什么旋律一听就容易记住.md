# 小室進行不是走红的唯一答案

## “小室進行”不是作者认定的成功秘诀

在 Billboard JAPAN 专访中，黒うさP说《千本桜》使用了通常称为“小室進行”的和声走向，并推测它也许更容易理解。但他随后举出和声走向不同的《リスキーゲーム》也达到百万播放并收到许多翻唱，提醒和弦走向未必是走红的决定因素。这是作者的实际保留意见，不能只摘前半句写成“成功秘诀已由作者证实”。（C-S02）[[segment:s009]]
