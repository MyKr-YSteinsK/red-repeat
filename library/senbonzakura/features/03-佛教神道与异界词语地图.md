# 佛教、神道与异界词语地图

## 「三千世界」和「常世」不是同一个体系

「三千世界」是佛教三千大千世界的简称；其中的“三千”指小千、中千、大千层级，不是普通计数的三千个独立世界。（C-S07）「常世」在辞书中可指古代人想象的海彼方异乡、不老不死之国；「常世の国」另有辞典释为死者所往的永远世界、黄泉。词义有不同传统，不能把歌词里的词强锁定成其中一种。（C-S06）[[segment:s013]]

因此，原译只用“黄泉之暗”会压扁「常世」的多层意思；但也不能反过来说它“绝不可能有黄泉含义”。本包选择保留“常世”这个名称，让文化说明承担多义，而不武断确定歌词场景。[[segment:s013]] [[segment:s014]]

## 「禅定門」的门、称号与句法

日语辞书对「禅定門」至少列出禅定的入口、入佛门的男子，以及男性戒名所用称号。前一义有“门”的空间画面，后两义是身份／称号；单凭歌词不能确认作者只取其中一种。（C-S08）[[segment:s022]]

但句子同时用了「を潜り抜けて」（穿过、钻过），这使“穿越禅定之门”成为能顺畅接上动词的编辑译法。本包的中文候选选择保留这个“门”的可视化入口，同时在逐句审查表明确列出它不是已证的唯一解释，更不能译成“穿过出家僧人旁”。[[segment:s022]]

## 净土、除厄和驱灵不是同义术语

「安楽浄土」是佛教净土用语；「厄払い」的辞典义包括向神佛祈祷以去除附身的秽气，辞典也另列近世门付艺与歌舞伎台词式的用法。「悪霊退散」是驱逐恶灵的口号式表达。把这些词连同「三千世界」并置，营造的是宗教与民俗语汇密集交错的意象，不是作者在完整阐释某一教义。（C-S10、C-S11）[[segment:s004]] [[segment:s023]]
