# 佛教、神道与异界词语地图

《千本桜》大量借用宗教和异界词汇，但这些词并不属于一个整齐统一的教义体系。

`悪霊退散` 是驱逐恶灵的祈祷式表达；`三千世界` 是佛教的宇宙论词汇，是“三千大千世界”的简称；`常世` 则来自日本古代对海彼方、永恒之国、异界的想象。把 `三千世界` 与 `常世之闇` 连在一起，是把佛教宇宙尺度和日本古代异界观压缩到一句歌词里。[[segment:s004]] [[segment:s013]]

第二段又出现 `禅定門`。这个词既可指进入禅定之门，也可用于佛教语境中的男性称号、戒名用语。紧接着的 `安楽浄土` 指向净土想象，`厄払い` 却更接近日常日本宗教生活里的除厄、祓除。[[segment:s022]] [[segment:s023]]

这些词共同制造“彼岸、死亡、超越、驱邪”的语感，但不应被解释成黒うさP在阐述一套完整宗教学说。歌曲真正做的是借词语的文化重量，让高速旋律里突然出现巨大的生死尺度。

**RED:REPEAT 编辑观察：** 当副歌唱到声音“传不到”、黑暗遍及“三千世界”时，歌词的空间已经不再是普通城市街道；它从近代日本的街景瞬间推到宇宙和彼岸，这种尺度跳跃正是歌曲戏剧感的一部分。[[segment:s010]] [[segment:s014]]
