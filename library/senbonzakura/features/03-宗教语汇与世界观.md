# 宗教语汇与世界观｜Religious Vocabulary & Worldview

## 词语线索

歌词把宗教、仪式与战争性的画面放在一起：[[segment:s004]] 写「悪霊退散」，[[segment:s013]] 写「三千世界」「常世之闇」，[[segment:s020]] 写「聖者の行進」，而 [[segment:s022]]–[[segment:s024]] 连续出现禅定门、安乐净土、厄払い与大团圆。

这些词可以帮助学习者理解画面来源，但不能据此断言歌曲只表达某一套宗教教义。它们在歌词中被重新编排为节奏、口号和舞台意象；中文翻译保留了原句的方向，日文 canonical text 与 ruby 则继续作为可核对的原始层。

## 学唱观察

[[segment:s009]]–[[segment:s016]] 的副歌把黑暗、听不见的声音、青蓝天空与光线枪连续切换；[[segment:s026]]–[[segment:s027]] 又把希望之丘和闪光弹带回同一类高密度画面。练习时可以先按音节入口跟唱，再回看汉字读音，不需要先把所有意象解释成唯一答案。
