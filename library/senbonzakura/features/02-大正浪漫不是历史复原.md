# 大正浪漫不是历史复原

黒うさP 自己在访谈中用过“日本”“大正ロマン”来描述《千本桜》的整体想象。但歌词并没有老老实实停在大正时代：`ハイカラ` 带出明治末到近代日本对西洋风尚的想象，`日の丸印の二輪車`、`将校` 又把国家、军装和现代交通放进画面；到了第二段，江户游郭文化中的 `花魁道中` 也闯了进来。[[segment:s001]] [[segment:s003]] [[segment:s017]] [[segment:s018]]

`ハイカラ` 本来来自英语 *high collar*。明治后期，这个词从高领洋装延伸为“西洋式、时髦、追逐新风尚”的说法。所以开头的 `ハイカラ革命` 天然带着一种“旧日本正在被新式样撞开”的质感，而不是单纯的“华丽”。[[segment:s001]]

更明显的错位来自武器：`ICBM`、`光線銃`、`閃光弾` 与 `断頭台` 同时存在。洲际弹道导弹属于现代军事技术，“光线枪”甚至带有科幻色彩；断头台又来自完全不同的历史语境。[[segment:s004]] [[segment:s012]] [[segment:s016]] [[segment:s027]]

因此，《千本桜》的世界更像一张**时代拼贴画**：和服、军服、花魁、火车般的速度感、现代武器和未来武器被压到同一个舞台。这里的“大正浪漫”是一种美术和情绪入口，不是历史教科书式的年代复原。

**RED:REPEAT 编辑观察：** 这种故意失真的时间感，正好解释了为什么歌曲既“复古”又“现代”。听者能认出很多日本文化符号，却很难把它们锁定在一个真实年份；作品因此获得了一种虚构舞台剧般的自由。
