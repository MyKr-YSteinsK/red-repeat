# 大正浪漫不是历史复原

## 「ハイカラ」不是“维新革命”的同义词

黒うさP 在访谈中以“日本”“大正ロマン”描述过歌曲的想象背景，但没有声称歌词逐一对应一个真实年份。（C-S02）开头的「ハイカラ」来自英语 high collar，日语辞书记录了它由高领西装与洋行风尚，扩展为西洋式、时髦、追新潮的用法。所以「ハイカラ革命」更接近“时髦／西洋新潮的革命”，不是词义上固定指称“明治维新”。（C-S05）[[segment:s001]]

歌词还把日之丸标识的二轮车、军官形象与环状线的都市速度置于同一舞台。这里出现的是可辨认的近现代符号，不应未经来源就把特定公路、军服型号或历史战役说成作者原型。 [[segment:s003]] [[segment:s005]]

## 花魁与导弹为什么会同时出现

「花魁道中」指江户时代知名游郭里，上妓前往茶屋迎接熟客及往返的行列；也可指上妓在特定日于郭内巡行。辞书描述的是花魁的行进，不是凭空补出的“往来人潮”。它与歌词中的大正罗曼自述并置时，更能看出这些意象来自不同历史层次；本文不把这种拼贴当作单一年代的复原。（C-S09）[[segment:s018]]

另一头，ICBM 是“洲际弹道导弹”（intercontinental ballistic missile）的缩写（C-S13）；「光線銃」带有科幻式的武器意象，「断頭台」则将刑罚或恐怖的视觉置于欢宴之中。将它们并读可以解释作品的年代错位；但“作者刻意将每件武器编码成某种政治势力”并无所查作者访谈支持。（C-S02，后半属编辑观察） [[segment:s004]] [[segment:s011]]
