# 从初音未来独唱到「25時、ナイトコードで。」三声部

《妄想感傷代償連盟》不是为《Project SEKAI》创作的歌。它在 2016 年已经发行；2022 年 5 月才作为既有 VOCALOID 曲加入游戏。

官方追加信息确认了两种音源：

```text
Virtual Singer ver.
初音未来

SEKAI ver.
初音未来 + 宵崎奏 + 東雲絵名
```

也就是说，这是一种 **retrospective adoption / 后来采用**，不能倒推成 DECO*27 当年在为奏、绘名或 Nightcord 写歌词。

但新的演唱配置确实改变了听法。原版是一位初音未来从头唱到底，像一段高速内心独白；SEKAI ver. 把同一首歌拆给三种声音。像下面这种本来就具有问答感的句子，在多声部版本里会更容易被听成角色之间的交错：

[[segment:s030]]

而「阿吽の呼吸でズレるビート」本身就在写“明明像有默契，却仍然错拍”。[[segment:s031]]

后来游戏还为这首歌追加了原创 2DMV，使它不再只是音乐商店中的旧曲收录，而获得了新的视觉入口。

**官方事实：** Project SEKAI 选择的是初音未来、宵崎奏、东云绘名的 SEKAI ver.，并保留初音未来 Virtual Singer ver.

**RED:REPEAT 编辑观察：** 不需要把恋爱歌词硬套成角色剧情，多声部本身已经足够有意思：2016 年一个人的自我争辩，在 2022 年以后可以被听成几个人轮流接过同一套“没问题 / 其实有问题”的语言。
