# 三次「大丈夫」：不存在、还是相信、最后学会说谎

## 第一次：否认一种安全的恋爱

第一处「大丈夫」并不安慰任何人。歌词的判断是：所谓“没问题”的恋爱，哪里都找不到。[[segment:s019]] 前文还说，把“最讨厌”翻过来并不必然找到“最喜欢”。[[segment:s011]] [[segment:s012]] 这让副歌的乐观口号出现裂缝：当事人并非不知道矛盾存在，而是没有找到足够可靠的简单答案。

## 第二次：明知如此，仍会选择相信

第二轮换了一个动词：不是“那样的恋爱不存在”，而是“还是会相信那样的恋爱”。[[segment:s036]] 同一词语在两段副歌之间完成了从判断到寄托的变化。它前面还出现“生气了吗？”“没生气”的短问答，以及自称默契却错拍的呼吸。[[segment:s030]] [[segment:s031]] 即便无法替歌词指定唯一的一对角色，这套语言本身已经表现出否认与期待同时存在。

## 第三次：学会了「大丈夫」这句谎言

第三处的变化最小也最重：主角不是“发现别人说了谎”，而是自己渐渐学会了名为「大丈夫」的谎言。[[segment:s043]] 这条弧线可概括成“认为不存在 → 仍愿意相信 → 学会拿它遮掩”。歌词并未规定谁先说谎、谁是加害者，也不应被转译成对现实关系的医学诊断。

**RED:REPEAT 编辑观察：** 标题中的“代償”可被读作这三次自我安慰的成本。这个解释来源于相邻歌词的语法变化，不是 DECO*27 在访谈中逐句给出的标准答案。
