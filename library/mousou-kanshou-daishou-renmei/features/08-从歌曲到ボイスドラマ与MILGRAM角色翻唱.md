# 从歌曲到ボイスドラマ，再到 MILGRAM 角色翻唱

《妄想感傷代償連盟》的跨媒体生命并没有停在音乐游戏。

2019 年 DECO*27 的《アンドロイドガール》初回限定盘附带了一张特典 CD，其中直接收录名为《妄想感傷代償連盟》的ボイスドラマ。官方商品信息列出的出演者是浅沼晋太郎、雨宮天，脚本由内田裕基负责。内田裕基本人后来说明，这是以 DECO*27 这首歌为基础新写的、带有苦涩感的原创故事。

这件事很特别：歌词原本没有给主人公姓名，也没有把“联盟”建成一个明确世界观；到了 voice drama，歌曲里的关系冲突第一次被真正扩写成有演员、有对白的叙事作品。

几年后，它又进入 DECO*27 担任声音制作人的企划《MILGRAM》。官方在ムウ第二审 CD《悪くないもん》中收录了她演唱的《妄想感傷代償連盟》Cover。这里同样属于后来选择的角色翻唱，不应说原曲本来就是为 MILGRAM 或ムウ创作。

这两句关于「大丈夫」的变化，很适合说明为什么这首歌容易被拿去做角色叙事材料：它没有提供具体剧情，却提供了一套可以套进不同人物关系的心理结构——否认问题、相信安慰、最后学会拿安慰当谎言。

**官方事实：** 2019 voice drama 与 MILGRAM 角色翻唱都是真实发行/企划记录。

**RED:REPEAT 编辑观察：** 《妄想感傷代償連盟》的跨媒体能力来自“结构比剧情更具体”：人物是谁可以替换，但自我欺骗、关系错拍和反复补偿的机制非常清楚，所以它能从初音未来独唱长成声剧，也能被另一套角色世界重新演唱。
