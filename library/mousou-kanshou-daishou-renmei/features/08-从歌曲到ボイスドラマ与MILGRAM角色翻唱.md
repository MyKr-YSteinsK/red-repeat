# 一首歌如何成为声剧标题与其他角色的翻唱曲

## 2019 年的声剧是可核实的商品内容

2019 年 5 月 22 日发行的《アンドロイドガール》初回限定盘，附赠 CD 中列有ボイスドラマ《妄想感傷代償連盟》。发行方 NBCUniversal 的商品目录列出演员浅沼晋太郎、雨宮天以及脚本内田裕基。这里可以确认**剧名、媒介形式、制作署名和发行载体**；不凭商品信息编造剧中角色关系、情节高潮或“这必定是第一部改编”。

## 2020 年和 MILGRAM：继续成为可由别人演唱的素材

《ACTORS -Singing Contest Edition-》官方收录表还列出五月女燎（CV：坪井智浩）的翻唱。其后 MILGRAM 官方公告明确记载，ムウ第二审 CD《悪くないもん》收录《妄想感傷代償連盟》翻唱及另行创作的 voice drama。这说明歌曲能在不同角色企划中被重新使用，但绝不能反推这些虚构角色本来就是 2016 年歌词的原型。

## 为什么它能离开原本的“我”和“你”

原曲不给“我”与“你”固定姓名，却有强烈的关系组织方式：否定一种没有问题的恋爱，仍然相信它，最后学会同样的谎言。[[segment:s019]] [[segment:s036]] [[segment:s043]] 还有一句已经可直接作为对白的“生气了吗？……没生气”。[[segment:s030]] 这使后来的发行方能在不改变最初词曲作者身份的前提下，为新媒介安排具体演员或角色。

**发行事实：** 2019 声剧 CD、ACTORS 翻唱、MILGRAM 曲目。**RED:REPEAT 编辑观察：** 强结构、弱固定角色设定的歌词，特别容易被不同企划“重新讲述”；这不是原作人物的官方连载。
