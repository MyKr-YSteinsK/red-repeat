# 字形与现行注音层的错位：眼睛和阅读标注给出不同信息

## 字写得很重，现行标注却很口语

本项目现有 Ruby/Romaji 将「一時」标作「ちょっと」，把「鬱雑い」标作「うざい」。前者把“再一会儿”的请求写得郑重，后者把轻率的一句“烦死了”塞进很沉重的汉字。两种字形都可在一份署名 DECO*27 的公开歌词页面中核对；此处只用它核对书写，不把平台页面或仓库注音当成作者对实际唱法的直接证明。这里比较的是公开书写与仓库现有阅读标注；本次审稿没有独立复听音源，不能把标注写成新的人耳验证。[[segment:s002]] [[segment:s003]]

## 「理想乡」与「理想狂」挤在同一行

「思い笑描く理想狂」保留了「笑」和「狂」两个可见字形。当前 reading 标注把它指向「思い描く理想郷」的近似读法，因此读者可以同时注意到“理想乡”与“理想狂”的字面差别。翻译若只写正常的“理想乡”，会失去汉字造成的歪斜；若只写“疯狂理想主义者”，又会失去读音标注所提示的另一层。[[segment:s017]] 这些是对文字和现行标注的对照，不是本轮对实际唱法的确认。

## 「自恋魔」与「悪んで」都不能只看字面

「謎自恋魔」的当前 reading 标注是「なぞ／じれんま」，后半近似「ジレンマ」；字面却保留了「自恋魔」。因此译文可以同时让读者看见两难与视觉双关，但不该把它解释成医学意义上的自恋人格。[[segment:s029]] 「愛を悪んで」则让本可写作「憎んで」的情绪换了一个字，与随后守住的“位相”相接。[[segment:s038]] 同一首歌既使用自然口语，也持续让书写外壳变形。

**证据边界：** 创作者公开文本可以确认特殊字形；仓库当前 Ruby/Romaji 可以确认项目保存了哪些读音标注。二者都不能替代对目标音源实际唱法的独立核验。**RED:REPEAT 编辑观察：** “嘴上像能说清，写下来却歪了”的效果，与三次「大丈夫」的关系变化相呼应。[[segment:s019]] [[segment:s043]]
