# 鬱雑い、理想狂、自恋魔：DECO*27 怎样把“错字感”写成机关

《妄想感傷代償連盟》的歌词里有一批看上去像错别字、实际却必须按特殊读法唱的表记。官方歌词本身就保留了这些写法，所以它们不是 LRC 的随机乱码。

最早出现的是「もう一時だけ隣りに居たい」。这里的「一時」实际唱成「ちょっと」，于是字面像一个郑重的时间单位，声音却只是很轻的“再一会儿”。[[segment:s002]]

紧接着的「鬱雑い」唱成「うざい」。普通口语往往直接写成假名，DECO*27 却给这个嫌烦的语气套上一组很重的汉字。[[segment:s003]]

真正把机关推到极致的是「思い笑描く理想狂」。实际听感对应「思い描く理想郷（在心里描绘理想乡）」，但视觉上多了“笑”，又把“郷”换成“狂”。于是同一串声音同时装着“理想乡”和“理想狂”。[[segment:s017]]

第二段的「謎自恋魔」同样如此：「自恋魔」唱成「ジレンマ（dilemma）」。它不是在说一个“神秘自恋狂”，而是把外来语“两难困境”硬装进三个汉字里。[[segment:s029]]

还有「愛を悪んで」——「悪んで」唱作「にくんで」，本来更常写成「憎んで」。当“憎爱”被写成“恶爱”，字面本身就开始扭曲。[[segment:s038]]

这些机关共同说明：这首歌不能只按“汉字字面”翻译。它经常先让耳朵听见一句普通表达，再让眼睛发现文字已经变形。

**RED:REPEAT 编辑观察：** 歌词里的关系也在做同一件事——嘴上说“没问题”，写出来的世界却处处不对劲。特殊表记不是装饰，而是在文字层面重复了这种“声音正常、结构失真”的关系状态。
