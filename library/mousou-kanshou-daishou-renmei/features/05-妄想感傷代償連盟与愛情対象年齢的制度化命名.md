# 「妄想感傷代償連盟」与「愛情対象年齢」：给感情强行建一套制度

标题本身就是一个奇怪的组织名。

「妄想」「感傷」「代償」都是抽象心理词，最后却接上「連盟」，仿佛这些情绪真的成立了一个机构。官方 MV 对外还使用过 `MKDR / DSCF` 这样的缩写，更让标题像某个有正式名称的团体。

副歌唱出来时，这个“联盟”没有明确成员名单：

[[segment:s020]]

因此，不应该把它解释成作品世界里真实存在的组织。更安全的读法是：DECO*27 故意把私人、混乱、难以命名的感情，包装成一个过度正式的制度名称。

第二轮副歌继续做同样的事：

[[segment:s037]]

「対象年齢」通常是商品、作品、设施上的“适用年龄”。前面加上「愛情」，恋爱突然也像需要贴标签、划年龄区间的东西。最终副歌又把它作为“通称”重复一次。[[segment:s045]]

这两组命名有相似结构：

```text
妄想 / 感傷 / 代償
→ 连盟化

愛情
→ 対象年齢化
```

私人情绪被强行行政化、分类化、命名化。

**RED:REPEAT 编辑观察：** 当一段关系已经无法靠“喜欢/讨厌”解释时，歌词开始发明制度、术语和组织名。这些名字越完整，反而越能看出当事人其实没有答案。标题的中毒性，很大一部分就来自这种“把混乱说得像规章制度”的荒诞感。
