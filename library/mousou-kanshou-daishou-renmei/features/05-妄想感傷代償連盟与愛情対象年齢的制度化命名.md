# 标题像一个组织，「愛情対象年齢」又像产品标签

## 私人情绪被包装成“联盟”

「妄想」「感傷」「代償」各自都能表达心理反应，连在一起又接上「連盟」，像是为无法整理的感情成立一个正式组织。[[segment:s020]] 这是由歌词用词引出的编辑观察；歌词并没有因此建立一套真实的成员、规章或世界观。

## 不是每个名词都在要求字典释义

第二轮将「通称」与「愛情対象年齢」连用。[[segment:s037]] 「対象年齢」常见于商品或作品的适用年龄标注，而「愛情」把私人经验推入分类语法。末尾再次出现这个通称，像先前的命名变成了重复使用的标签。[[segment:s045]] 译文可以保留“适用年龄”的制度口气，但不宜解释成法律上的交往年龄、某个确定角色设定或对未成年关系的实指。

## 命名代替不了解决

标题说“联盟”，下一轮说“通称”，而两处之间仍是无处安放的旋律、不断再挑战与反复伤害。[[segment:s022]] [[segment:s023]] [[segment:s041]] 名称变得越来越完备，矛盾并未消失。这里可以与另一篇的“相位／润滑液”互相参照，但分工不同：本篇分析正式名称如何产生秩序错觉，另一篇分析关系如何表现出失步。

**RED:REPEAT 编辑观察：** 歌词让人听见某种自我管理的幻觉：给感情起一个漂亮制度名，似乎就能掌控它。此处属于文本阅读，不是创作者公开宣告的寓意。
