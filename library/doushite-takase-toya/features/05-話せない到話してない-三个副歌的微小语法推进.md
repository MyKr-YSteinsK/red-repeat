# 「話せない → 話さない → 話してない」：三个副歌的微小语法推进

三个副歌里有一组很容易被中文翻译抹平的变化：

第一轮是「話せない」——还**无法说**；第二轮是「話さない」——还**不说 / 没打算说**；第三轮是「話してない」——到现在**还没有说**。

三者都可以被粗略翻成“还没告诉别人”，但日语的立场不同。第一轮把阻力放在“做不到”；第二轮更接近一个当前选择；第三轮则用进行/状态式回看已经持续到现在的事实。歌曲没有大幅改写副歌，而是通过这些很小的语法移动，让同一个失恋状态从卡住、维持到确认其持续存在。

类似的变化还发生在「諦めきれない」后面的句尾：「や」「な」「んだ」依次改变语气，从轻叹、自言自语到更明确的确认。
