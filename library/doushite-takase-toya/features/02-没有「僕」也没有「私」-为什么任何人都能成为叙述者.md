# 没有「僕」也没有「私」：为什么任何人都能成为叙述者

高瀬統也后来谈到《どうして》时，特意指出一个容易被忽略的设计：歌词里没有出现「僕」或「私」，真正被反复点名的只有「君」。他的解释很直接——这样无论由男性还是女性演唱，听者都更容易把歌曲投射到与自己性别和关系经验相符的恋爱里。

这也是野田愛実作为 featuring vocal 并不会让歌曲变成“固定男女角色对唱剧”的原因。歌曲没有在文字上规定谁是谁，两个声音更像共享同一份失恋独白，而不是被剧情明确分配成“离开的人”和“被留下的人”。

这种写法还让「U&I」变得更有意思：英语把关系压成“you and I”，日语正文却仍然拒绝给“我”一个性别化的人称代词。听者知道存在一个叙述者，却很难从歌词文本本身把这个叙述者钉死。

**已确认事实**：高瀬统也在 BARKS /《Artist#18File》采访中明确说明没有「僕」「私」、只出现「君」，并说明这种写法允许不同性别的演唱者聚焦于自己的恋爱语境。其余关于“双声部共享独白”的描述是 RED:REPEAT 对文本与演唱结构的编辑分析。
