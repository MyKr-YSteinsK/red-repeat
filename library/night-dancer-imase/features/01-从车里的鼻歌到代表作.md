# 从车里的鼻歌到代表作

imase 回忆，《NIGHT DANCER》的旋律是在活动初期一次开车途中冒出来的。他先把鼻歌录下来，回家后马上打进工程。当时自己的作品大多偏 chill、偏松弛，他刻意想做一首更能让身体跟着动起来的歌。于是，这首后来成为代表作的舞曲，起点其实非常日常：车里的一段旋律和一个想让节奏更“能跳”的念头。[[segment:s001]] [[segment:s016]]

最早写下的核心句也是开头。imase 后来透露，这一句原本用的是更积极的说法，随后为了让开口的浊音更有冲击力，改成了现在这句带点漫不经心的表达。这个微小变化同时改变了叙事入口：夜晚表面上似乎无所谓，句尾却马上留下转折，因此后面的靠近、犹豫和邀请都能从这种若即若离的姿态继续展开。[[segment:s001]]

**创作者陈述：** imase 说这次改词首先来自“语感”判断，并且认为正是这个变化让后续故事更容易写下去。

**RED:REPEAT 编辑观察：** 这也是全曲最重要的张力来源之一。它没有一开始就把关系说得很热，而是先摆出一种“随便啦”的夜间姿态，真正的欲望被压到后段才露出来。因此从第一句到最后的情绪上升，会比一开始就直白告白更明显。
