# ESME MORI 如何把它推向舞池

《NIGHT DANCER》的词曲由 imase 完成，编曲与制作的重要部分由 ESME MORI 承担。发行期资料把它描述为带有锋利合成器、浮游感假声和舞曲节奏的作品；几年后 imase 自己再回看时，更直接点出了 ESME MORI 加进来的关键成分：偏 K-Pop / house 的可舞性、克制的音数，以及有明显音压的鼓组。[[segment:s016]] [[segment:s029]]

“音数少”并不等于编曲简单。相反，它让每个进入的元素更容易被听见：鼓组负责推动身体，低频和和声保持循环，合成器与人声留下足够空间。imase 的声线因此不会被厚重伴奏埋住，轻声、假声和短促咬字都能成为节奏的一部分。

imase 后来甚至认为，这套编曲对歌曲在韩国被听见非常重要。这个判断不能简化成“韩国喜欢 K-Pop，所以歌曲成功”，但它至少说明：跨国传播并不是只靠歌词或 TikTok 片段，最终完整音源的律动语言同样决定了作品能不能被反复播放。

**RED:REPEAT 编辑观察：** 对学唱来说，这也解释了为什么脱离伴奏后会觉得旋律比想象中“空”。原曲的魅力有很大一部分来自人声和节拍互相留白，而不是把每一拍都唱满。
