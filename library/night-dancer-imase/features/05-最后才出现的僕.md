# 最后才出现的「僕」

《NIGHT DANCER》前面很长一段都避免把叙述者直接钉死成一个鲜明的“我”。人物在回忆、犹豫、观察，也不断邀请对方继续跳舞，但真正直接的占有欲被留到了最后。[[segment:s032]] [[segment:s033]]

这不是偶然。imase 在访谈中明确说，他希望结尾变得更热，所以前面刻意不出现第一人称，直到最后才让“僕”突然站出来；同时最后一段旋律也做了轻微变化，用来表现心情真的开始移动。换句话说，结尾不只是“再唱一遍副歌”，而是在叙事上完成了一次人物显形。

这也让前面反复出现的“无所谓”发生反转。到了这里，叙述者已经无法继续维持冷淡姿态：即便步子仍然摇晃，他说出的愿望却比此前任何一句都直接。[[segment:s034]]

**学唱观察：** Final Chorus 不必单纯靠音量做高潮。更有效的处理是保留前段的轻，再让最后几句的咬字和情绪明显向前；这样更接近这首歌“先克制、后露底”的结构。
