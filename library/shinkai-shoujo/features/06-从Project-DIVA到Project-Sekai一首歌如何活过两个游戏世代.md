# 《深海少女》进入 Project DIVA 与 Project SEKAI 关联专辑

## 旧作在节奏游戏中保留作品署名

SEGA 的《初音ミク Project DIVA Arcade Future Tone》及《Future Tone DX》官方曲目表都列有《深海少女》，并标明ゆうゆ及 ODESSA（はるよ＆マクー）的创作/视觉署名（C-H06）。这证明歌曲以原作名字和来源进入了官方游戏曲库；不能由此推算任何具体设备上的游戏版本、当前可下载情况或本机所用音轨与该游戏音轨字节一致。

## 已能核实的 2024 多人歌唱版本

更晚一层的证据来自 KARENT 的《MORE MORE JUMP！ SEKAI ALBUM vol.2》页面：页面记录《深海少女》于 2024 年 2 月 7 日发行，并列出花里みのり、桐谷遥、桃井愛莉、日野森雫和初音ミク的共同演唱署名（C-H07）。这核实了 Project SEKAI 关联专辑中的多人演唱版本；它本身不证明歌曲在游戏内的追加日期，也不证明任何“Another Vocal”条目或逐句声部分配。

原曲先以“我”展开叙述，也写到不敢袒露内心、仍想了解更多。[[segment:s027]] [[segment:s041]] 当同一首歌在后来的企划中被多人演唱时，听者会有机会从不同声线重新理解这些语句。**具体分句由谁唱、哪里做和声**必须实际播放该发行版才可确认；仅凭曲目署名不能编造声部分配。

## 两个传播语境，不是两种“原作意图”

《Project DIVA》偏重把既有 Vocaloid 歌曲呈现为可游玩的曲目；《Project Sekai》相关专辑则把歌曲放进角色共同演唱的新语境。该区别可帮助用户分清“本项目当前 Edition”和其他正式版本，但不表示ゆうゆ当初就为 MORE MORE JUMP！中的任何人写作。
