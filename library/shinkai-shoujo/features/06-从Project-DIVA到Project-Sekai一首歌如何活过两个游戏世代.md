# 从 Project DIVA 到 Project Sekai：一首歌如何活过两个游戏世代

《深海少女》后来进入 SEGA 的《初音ミク Project DIVA Arcade Future Tone / Future Tone DX》。官方曲目表同时列出ゆうゆ和 ODESSA 的 credit，意味着玩家接触的不只是音源，而是被节奏游戏重新包装的一整套 Vocaloid 作品记忆。

到了 2023 年，它又进入《プロジェクトセカイ カラフルステージ！ feat. 初音ミク》。SEGA 公布的版本包括初音ミク的 Virtual Singer Ver.，以及初音ミク与 MORE MORE JUMP！成员共同演唱的 Sekai Ver.；2024 年又为歌曲追加了桐谷遥、日野森雫、MEIKO 的多个 Another Vocal。

这里不要过度解读：官方“把歌分配给某个游戏 unit”并不自动等于歌词原本就在写那个角色。真正确定的事实是，一首 2010 年的 Niconico 原创曲，在十多年后仍不断被重新演唱、重新游玩，并进入新一代面向手机玩家的虚拟歌手企划。

这也会改变学唱体验。原曲的“深海少女”只有一套ミク声线，但 Project Sekai 让听众直接比较不同声线如何处理同样的“沈む”“知りたい”“飛び立つ”。[[segment:s013]] [[segment:s015]] [[segment:s043]]

**RED:REPEAT 编辑观察：** 《深海少女》的 ACGN 浓度并不来自动画 tie-in，而来自 Vocaloid 本身的跨媒体生命：网络投稿 → 视觉形象 → 节奏游戏 → 多角色翻唱。歌曲没有固定在 2010 年，而是在不同平台上不断被新一代听众“重新遇见”。
