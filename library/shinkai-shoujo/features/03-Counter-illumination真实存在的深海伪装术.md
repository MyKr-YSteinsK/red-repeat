# Counter-illumination：真实存在的深海伪装术

“無意識のカウンターイルミネーション”是《深海少女》里最奇特的一句。[[segment:s011]] 它听起来像科幻词，其实 counter-illumination（反照明/逆照明伪装）是真实的海洋生物适应策略。

Smithsonian 对深海生物的说明很直观：从下方看，动物会在上方残余光线前形成黑色轮廓；一些生物利用腹侧发光器，让自身亮度接近从海面方向落下的微弱光，于是轮廓更难被捕食者看见。换句话说，它不是“为了照亮自己”，而是**为了通过发光让自己消失**。

把这个事实放回歌词，后面紧跟的却是“嘘つきは誰？”[[segment:s012]] 少女明明看见了光，也已经被吸引，却还在无意识地做“让自己不被看见”的事。到第二段，她甚至直接说没有脸去见任何人，只想别人别管自己。[[segment:s031]] [[segment:s032]]

这里需要区分证据：counter-illumination 的生物学含义是事实；ゆうゆ没有在现有公开材料中逐字说明“这一句就是某种心理防御机制”。

**RED:REPEAT 编辑观察：** 正因为这个术语真实表示“主动发光以隐藏轮廓”，它几乎天然成为全曲最精准的自我伪装隐喻。少女不是没有颜色，而是在努力把自己的颜色藏掉。后面“君も素敵な色を隠してた”才因此像一次反向揭露。[[segment:s038]]
