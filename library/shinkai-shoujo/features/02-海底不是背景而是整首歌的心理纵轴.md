# 海底不是背景，而是整首歌的心理纵轴

## 从被动下沉到第一次见光

《深海少女》的“海”既是视觉地点，也是用动作描述心境的叙事空间。开场的“沈んだ”把少女置于已下沉的状态；紧接着，连睁眼都嫌麻烦、是否会无人发现的疑问，使海底与退缩的状态联系起来。[[segment:s001]] [[segment:s002]]

光第一次照进来时，歌词用的是条件式：伸手的话**似乎**就能够到，但随后波浪与“看不见了”的变化打断了靠近的可能。[[segment:s007]] [[segment:s008]] 这里不要擅自判定是浪卷走了少女、光，还是二者之间的距离；日文保留了省略。

## 副歌把“躲起来”和“想了解”并排

第一段副歌不是单一的悲伤宣告。“まだまだ沈む”之后紧跟向黑暗深处封闭自己；然而“だけど知りたい”又明确转向求知与靠近。[[segment:s014]] [[segment:s015]]

后句说明：她已经找到了令自己心动的人。[[segment:s016]] 同一段落里既有向下的惯性，也有无法停止的好奇。

第二段把这个矛盾进一步具体化：她看着游动中的“你”，光再次洒下；目光对上之后，却称自己为“说谎的我”。[[segment:s020]] [[segment:s024]] “谎言”究竟指掩饰喜欢、伪装镇定，还是对自己价值的否定，没有足够的创作者证据可以定为唯一解。

## 方向反转不等于自动获得拯救

高潮前，少女觉得衣服已经弄脏、笑容变形，甚至不愿见任何人。[[segment:s029]] [[segment:s031]]

但对方突然不见后，她的动作从“伸手似乎碰得到”转为直接“把手伸出去”。[[segment:s037]]

接下来才发生被拉住手腕与离开海面的动作。[[segment:s039]] [[segment:s043]]

**RED:REPEAT 编辑观察：** 全曲可沿“向下沉 → 光照入 → 犹豫靠近 → 主动伸手 → 离海起飞”阅读。这是一条由歌词动作支持的情绪路线，但不是心理疾病的诊断，也不能说作者确认每个动作只象征某一种心理状态。
