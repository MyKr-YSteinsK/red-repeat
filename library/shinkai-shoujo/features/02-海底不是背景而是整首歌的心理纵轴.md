# 海底不是背景，而是整首歌的心理纵轴

《深海少女》当然可以画成真实海底，但歌词的第一层语法已经说明“海”同时是一种心理空间：悲伤让“我”下沉，连睁眼都嫌麻烦，也怀疑自己会不会永远没人发现。[[segment:s001]] [[segment:s002]] [[segment:s004]]

光第一次出现时，少女会伸手，却立刻又被波浪带走。[[segment:s006]] [[segment:s007]] [[segment:s008]] 到副歌，她一边继续下沉，一边第一次承认自己“想知道”那个令人心动的人。[[segment:s013]] [[segment:s015]] 所以全曲并不是简单的“黑暗 vs 光明”：光已经出现，真正困难的是她敢不敢承认自己正在被它吸引。

第二段把这个矛盾变得更明显。她看见对方自由地游动、觉得对方很美，等到目光真的对上，又马上称自己为“说谎的人”。[[segment:s019]] [[segment:s020]] [[segment:s024]] 随后的“赤い頬”“ハダカの心”都是暴露自身的信号，但黑海仍然“不允许”她迈出去。[[segment:s026]] [[segment:s027]] [[segment:s028]]

真正的动作反转发生在对方突然消失以后。少女从被动下沉的人变成“限界少女”，终于主动把手伸出去。[[segment:s034]] [[segment:s037]] 最后她被拉住手腕，在 marine snow 里唱歌，并用“离开这片海、现在飞起来”结束。[[segment:s039]] [[segment:s040]] [[segment:s043]]

**RED:REPEAT 编辑观察：** 这首歌最清楚的结构不是 Verse/Chorus，而是一个垂直坐标：沉む → 光が降る → 手を伸ばす → 腕を引かれる → 海を出る → 飛び立つ。情绪改变被写成了空间方向的改变。
