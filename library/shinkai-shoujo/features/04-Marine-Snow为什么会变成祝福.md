# Marine Snow 为什么会变成“祝福”

最终副歌出现“歌う祝福のマリンスノー”。[[segment:s040]] “marine snow（海洋雪）”也不是凭空造出来的浪漫词。

NOAA 对 marine snow 的定义是：海洋表层产生的有机物、微生物、悬浮颗粒等不断聚集并向深海下沉，看上去像水下持续飘落的雪。它可以花数周时间沉到深处，并为很多深海生物提供重要的能量来源。

这会产生一个很漂亮的反差：整首歌前面都把“向下沉”写成悲伤、封闭、失去方向；现实中的 marine snow 同样在向下落，但在最后却被称为“祝福”。[[segment:s013]] [[segment:s040]] 下降这个动作本身没有变，意义却被完全翻转了。

更关键的是，此时少女已经不是独自往下掉。她先伸手，对方再拉住她的手腕。[[segment:s037]] [[segment:s039]] 因而同样的深海、同样的下落颗粒，终于可以被看成景色，而不只是压力。

**已确认事实：** marine snow 是真实海洋现象，是由上层水体向深海持续下沉的颗粒物，并且是深海生态系统的重要食物/能量来源之一。

**RED:REPEAT 编辑观察：** 歌词把“下沉的东西”从悲伤改写成祝福，是结尾完成情绪反转时非常隐蔽的一笔。
