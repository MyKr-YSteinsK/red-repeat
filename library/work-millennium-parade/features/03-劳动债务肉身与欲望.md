# 劳动、债务、肉身与欲望

标题写作 `Ｗ●ＲＫ`，歌词却不断把“工作”扩展成更大的生存账本：`労働鼠`、`Wake Up Bankers`、`Pay Back!`、`今日も労働` 连在一起，劳动、银行、偿还和日复一日的循环被压成一组高频口号。[[segment:s010]] [[segment:s011]] [[segment:s012]] [[segment:s013]]

`労働鼠` 不是普通固定成语，更像歌曲自己造出的压缩意象：劳动者像不停运转的鼠。它很容易让人想到滚轮、消耗和循环，但“这首歌就是一篇反资本主义宣言”仍然超出了可确认事实。

另一条更重要的线是**身体**。前段把五体写成可被使用的容器，中段要求别人衡量技术、指出缺点，随后又说身处火线却还不能死。[[segment:s005]] [[segment:s017]] [[segment:s020]] [[segment:s022]]

到了后半，债务感从经济词汇变成伦理词汇：请求原谅、请求审判、请求劝诫，最后又希望通过所爱之人看见世界绝景。[[segment:s038]] [[segment:s039]] [[segment:s040]] [[segment:s041]]

欲望也没有被简单判为“坏”。`煩悩菩提です 恥と欲抱き抱え` 直接把羞耻与欲望抱在身上继续前进。[[segment:s023]]

**RED:REPEAT 编辑观察：** 这里的 WORK 更接近“活着必须不断支付的代价”。钱、罪、身体、欲望和亲密关系都在记账，而歌曲的答案并不是清零账本，只是“今天归今天，明天再继续烦恼”。[[segment:s058]] [[segment:s059]]
