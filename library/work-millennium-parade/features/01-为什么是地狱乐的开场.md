# 为什么是《地狱乐》的开场

《Ｗ●ＲＫ》是 TV 动画《地獄楽》第一期的 Opening Theme。官方音乐页面给出的核心 credits 很清楚：作词由椎名林檎与常田大希共同完成，作曲由常田大希负责。

这次合作并非临时把两位艺人拼到一起。常田大希在官方评论中回忆，约在 2019 年，两人已经在没有明确发表目的的情况下轻松地一起做过另一首歌；到 2023 年收到《地獄楽》主題歌邀请后，他认为这是适合二人的机会，于是重新邀请椎名林檎，为动画写了新的作品。这个时间线能解释《Ｗ●ＲＫ》为什么既像“首次正式合作”，又带着已经相识很久的默契。

《地獄楽》的故事核心之一，是被判死刑的画眉丸为了重新见到妻子而踏上极危险的岛屿；同行者又不断面对罪、处刑、求生、欲望和生死边界。《Ｗ●ＲＫ》里反复出现“还不能死”“原谅我”“审判我”“通过所爱之人看见绝景”等句子，与这种人物处境天然共振。[[segment:s022]] [[segment:s038]] [[segment:s039]] [[segment:s041]]

需要区分事实和解读：官方确认了这首歌为作品写下，也有创作者关于合作契机的明确说明；至于某一句是否“就是画眉丸”，属于媒体与听者的解释。Real Sound 曾把赦免、善恶与“爱する人”直接联系到《地獄楽》的叙事，这是一条有根据的作品分析，但不是逐句官方设定。

**RED:REPEAT 编辑观察：** 作为 OP，《Ｗ●ＲＫ》最有效的地方在于它不做剧情摘要。它把“罪人也要活下去”的压力转换成高速命令、审判和双声部冲撞，让观众在故事开始前先进入那种危险的身体状态。
