# 劳动、债务、肉身与欲望

## 歌词事实｜Lyric Facts

歌曲把 `労働鼠`、`Wake Up Bankers`、`Pay Back!` 和 `今日も労働` 连在一起，
再接上幻想、珍爱之人、身体缺点与仍然不能死的意志。这里的动作词有时像命令，
有时像自我鼓动，劳动不只是背景名词，而是人物每天必须重新进入的状态。

## 编辑解读｜Editorial Reading

从“欠账”“偿还”来听 `Pay Back!`，可以把它理解为债务、报复和回到自身的
多重回声；但这不是规定好的唯一释义。`WORK` 这个标题与这些词放在一起，产生
一种张力：人既是劳动的执行者，也是被消耗、被审问、想要取回某些东西的肉身。
后半段的请求——原谅、审判、劝诫——又把社会关系和亲密关系同时拉进这笔账。

因此，这首歌可以触发关于劳动、资本、身体与欲望的社会性联想，但不宜被压缩
成一篇单一政治宣言。歌词更像把多种代价叠在一起，让听者自己判断：所谓“回报”
究竟是钱、自由、赦免、爱，还是仅仅还有下一天可以继续。[[segment:s058]]
