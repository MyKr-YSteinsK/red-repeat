# 画眉丸、佐切与“两极之间”

《Ｗ●ＲＫ》后半段连续把弱与强、暗与光、女与男、憎与爱、正确与错误、罪与罚、生与死推到一起，最后才落在“两极之间”。[[segment:s046]] [[segment:s049]] [[segment:s050]] [[segment:s054]] [[segment:s055]] [[segment:s056]]

如果只看歌词，这已经是一套很明确的反二元结构；放回《地狱乐》，它会更有意思。原作者贺来友治在官方长篇访谈中明确说，作品并不是先拿一条哲学命题去套人物，而是在连载过程中逐渐浮现出“中道”、矛盾与葛藤。他还说，最初更以画眉丸的成长为轴，后来发现真正承接“中道”主题的人逐渐变成了佐切。

动画本身也反复用成对概念给章节命名：第一期有“弱さと強さ”“地獄と極楽”“陰と陽”“弱イと強イ”。这些标题当然不能反过来证明《Ｗ●ＲＫ》的每一组词都在逐集点题，但它说明歌曲和作品确实共享一种思考方式：人不是固定站在某一个极端，而是在矛盾两侧之间被迫移动。

这种结构在画眉丸与佐切身上尤其清楚。画眉丸拥有压倒性的战斗能力，却因为妻子和“想活着回去”重新认识自己的软弱；佐切看似是负责处刑、判断罪人的人，却不断怀疑自己的强弱、身份与“正确”。歌词中“通过相对之人，想知道自己身体的缺点”因此很容易让人想到这对搭档。[[segment:s020]]

后来的动画访谈中，画眉丸与佐切的声优也把二人的关系描述成彼此从对方身上看见自己需要的东西、在相处中逐渐改变。这属于演员对角色关系的理解，不是歌曲作者的逐句说明，但与歌词的“相对之人”形成了很漂亮的二次共鸣。

而《Ｗ●ＲＫ》另一句“通过所爱之人去看这个世界的绝景”，又把“他者”从对手推到亲密关系。[[segment:s041]] 对画眉丸而言，妻子并不是任务奖励；她是让一个从小被训练成杀人工具的人开始想象普通生活的原因。官方角色介绍直接写明，他为了最爱的妻子寻找仙药。

**RED:REPEAT 编辑观察：** 《地狱乐》的“中道”不是谁都各退一步，而是承认弱里有强、罪人也会爱、执刑者也会迷惘。歌曲把这些矛盾压成高速对句，再让两位主唱彼此接力，很像把作品的人物关系本身变成了声音结构。
