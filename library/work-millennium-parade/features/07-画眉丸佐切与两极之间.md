# 画眉丸与佐切：为什么《地狱乐》不把人固定在一端

## “中道”是写作过程中浮现的主题

在动画官方对《地狱乐》原作者賀来ゆうじ的长篇访谈中，他谈到“中道”、矛盾与内心葛藤如何逐渐成为作品的主题，并指出佐切在后来的创作中越来越承担这一层问题。这是漫画作者对自己作品的回顾，不是椎名林檎或常田大希对《Ｗ●ＲＫ》的逐句说明。

这一区别很重要：一首歌可以与作品共享值得探索的问题，却不必被读成从第一句到最后一句都对应人物的暗号。歌词成对排出弱与强、对与错、罪与罚；漫画则通过人物的处境，让这些标签失去简单划界的能力。[[segment:s046]] [[segment:s047]] [[segment:s052]] [[segment:s053]] [[segment:s054]]

## 极强的忍者为什么只想回到普通生活

画眉丸拥有可怕的生存与战斗能力，却仍希望与妻子重逢。危险的仙药任务对他并不是自我证明的舞台，首先是返回生活的一条道路。歌曲的“还不能死”与“通过所爱之人观看世界”因而非常适合放在他的人物处境旁边读。[[segment:s022]] [[segment:s041]]

但这是剧情与歌词的主题对照，不能进一步断言上述句子一定由画眉丸“发言”。当强大无法取消恐惧、希望和依恋，“强者”的标签就不足以说明这个人物。

## 挥刀的人也被自己的身份困住

佐切承担执行处刑的职责，同时也不断面对自己的犹疑、所受的规范和自身定位。她并非因为犹豫便不再是执行人，也不能因执刀就被简化为绝对正确的一方。

歌词有一句是希望借面对的他人认清自身不足。[[segment:s020]] 这描述的是说话者通过另一人的存在认识自己，而不是直接命令对方指出自己的缺陷。另一句则是真正的裁断请求——请以新的好坏标准审判我。[[segment:s039]] 这两种关系应该分开：相遇能让人看见自己，裁断才涉及由谁评价行为。

把这组区别放进画眉丸与佐切的同行关系，便能产生比“谁代表强、谁代表弱”更丰富的理解：彼此的存在改变了对力量、罪与正确的认识，但任何人都不能只凭一种身份获得全部解释。

## 两个作者、两套证据

漫画作者谈“中道”可以支持作品主题；歌曲确认为本动画新写 OP，可以支持二者存在创作联系；歌词中的相关词语又允许合理比较。三层证据加在一起，仍不能证明两位演唱者各自代表某位角色，或把每一句歌词指定给具体漫画分镜。

**RED:REPEAT 编辑观察：** 重新听《Ｗ●ＲＫ》时，不妨把人物关系当作一面镜子：一个人既可能是危险的忍者，也是想回家的丈夫；既可能负责行刑，也会怀疑自己。歌曲密集列出的对立词，因此更像持续要面对的矛盾，而不是待填答案的选择题。
