# 《Ｗ●ＲＫ》为什么像一场高速审判

《Ｗ●ＲＫ》由 millennium parade 与椎名林檎合作，并被采用为动画《地狱乐》第一期片头曲。作品把劳动、战斗、犯罪、欲望和救赎压缩在高速切换的双人声部中。

标题没有把 WORK 正常写完，而以圆点替代字母 O。这个空洞既像劳动循环的齿轮，也像被抽空的中心。歌词一面把人写成反复运转的“劳动鼠”，一面不断追问身体、名号和活下去的意义。[[segment:s010]]

歌曲并不提供一条稳定的胜利路线。它强调运气、缺陷、受审和反复劳动，人物只能通过对手与所爱之人认识自己。[[segment:s020]] [[segment:s041]]

因此，最适合它的不是英雄凯歌式解释，而是“在矛盾中继续行动”：今天归今天，明天仍要重新面对。[[segment:s058]]
