# 日英混杂、文字游戏与高密度歌词

## 语言切换本身就是节奏｜Language as Rhythm

`Ｗ●ＲＫ` 不把 Japanese 和 English 分成两块整齐的段落，而是让它们在同一
条推进线上快速切换：`Wake Up Bankers`、`One verse One Punch`、
`Stand up my fav people`、`Damn it!!!` 和 `Right now!!` 都像可以直接击出的
声音单元。它们与日文长句相邻时，意义会从叙述突然切到口号、命令或舞台动作。
[[segment:s011]] [[segment:s014]] [[segment:s016]] [[segment:s033]] [[segment:s037]]

日文一侧也有高密度的视觉组织：`名詮自性` 与 `銘采配` 把近音、字形和“名/铭”
的联想推到同一屏幕；这不是要求读者马上给出唯一语源，而是鼓励先看见文字
如何与发音、决断和身份互相牵引。[[segment:s003]] [[segment:s008]]

## 特殊表记为什么值得慢下来｜Why Ruby Matters

这首歌的几个表记不能只按常用汉字直读：`已` 标出 `のみ`，`慇懃尾籠無礼行為`
带着整句的特殊读法，`許り` 读作 `ばかり`，`咲う` 读作 `わらう`，而
`両極の間` 的 `間` 读作 `あわい`。这些位置都保留在 canonical Japanese
歌词中，再由 ruby 给出可验证的阅读入口。[[segment:s031]] [[segment:s032]]
[[segment:s035]] [[segment:s049]] [[segment:s056]]

对学唱来说，ruby / notes 的价值不只是“翻译生词”：它提醒学习者何时要忠于
歌词的特殊表记，何时不能用普通音读/训读替换作者选定的声音。最佳顺序是先听
整句的速度与重音，再用 ruby 确认发音，最后回看字形为什么这样写；不要把注音
当成脱离歌曲的词典答案。
