# 特殊表记与语言机关

《Ｗ●ＲＫ》的难，不只是语速快。很多字形故意不按现代日语最普通的写法出现，因此“看懂字”并不等于“会唱”。

`名詮自性` 之后出现 `銘采配`。歌网等歌词资料确认了 `銘` 这一字形；常见表达原本是 `名采配`，意为出色的指挥/判断。把 `名` 换成 `銘`，又紧邻前面的 `名詮自性`，很容易产生“名／铭／命名”的文字回声。这里没有找到创作者对该字的公开逐字解释，因此把它视为**编辑性文字游戏观察**更稳妥。[[segment:s003]] [[segment:s008]]

中后段还有一串特殊读法：`已` 按当前正式素材读作 `のみ`；`慇懃尾籠無礼行為` 把古老的 `慇懃尾籠` 与“无礼行为”叠成极其过量的礼貌/无礼词团；`許り` 读 `ばかり`，本身就是这个副助词的汉字表记。[[segment:s031]] [[segment:s032]] [[segment:s035]]

`科` 在 `嘗て犯した科` 中读 `とが`，是罪过、过失；`咲う` 读 `わらう`，把“笑”写成“开花”的字形；`両極の間` 的 `間` 读作古雅的 `あわい`；最后 `玉響` 读 `たまゆら`，表示极短的一瞬，`果敢ない` 则按 `はかない` 理解，指短暂、无常、难以长久。[[segment:s038]] [[segment:s049]] [[segment:s056]] [[segment:s061]]

这些表记的价值不是炫技。它们让同一条声音同时带着多个视觉联想：笑可以“开花”，两极之间不是普通的“あいだ”，短暂也不只写成常见的 `儚い`。

对学唱来说，最可靠的顺序是：先听实际发音，再看 ruby，最后回到字形理解它为什么值得这样写；不能反过来用常用汉字读法强行覆盖歌曲的声音。
