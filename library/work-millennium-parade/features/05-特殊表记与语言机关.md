# 一眼看见的字，和一句真正唱出的声音

## 名、銘与无法直接照读的字形

《Ｗ●ＲＫ》不只是在词语中塞入生僻汉字。它会同时利用字形、读音和语义之间的距离，令读者在熟悉的词旁重新停顿。

“名詮自性”是有辞书根据的词，通常读作“みょうせんじしょう”。[[segment:s003]] 歌曲又采用“銘采配”这一写法。它容易让人联想到通常所见的“名采配”与前文的姓名主题；但“銘”为何被选择，目前并没有可直接引用的作者逐字说明。因此可以观察这种视觉回声，却不能宣布已证实其创作意图。[[segment:s008]]

## 恭敬为什么会变成冒犯

“慇懃尾籠”不是随意拼出的四字。辞书记录了它与“慇懃無礼”相通的用法，指过度殷勤反而失礼，或表面恭敬却有傲慢意味。[[segment:s032]] 歌词再加上“無礼行為”，使礼貌与无礼之间的反差更加直观。

若仅译成“阳奉阴违”，听者会以为重点是暗地违背承诺；这里更值得保留的是：礼貌的外壳可能恰恰成为冒犯的一部分。词义的古老来历可以由辞书核实，而这串长词在本录音中产生的具体节奏效果，仍需音频证据。

## “許り”不是“允许”

“Play boy”所在句使用“許り”，按“ばかり”理解时是限定性的“尽是、净是”，不是许可别人的“允许”。[[segment:s035]] 若误译为“只允许正常位”，就把一句可能带着自我调侃的描述，改成了控制他人的指令。

另有几处值得分别观察：“科”保留了罪过的古雅写法；“咲う”同时使现代读者想到花开与笑。值得注意的是，字书记录“咲”有古代的笑义，所以不能说词作者凭空发明了“借花字表示笑”的字源。[[segment:s038]] [[segment:s049]] 结尾“玉響”“果敢ない”等写法又把转瞬的时间感压入词汇。[[segment:s061]]

## 学唱时要分清三种证明

第一层是原文确实写了什么；第二层是辞书或正式注音支持什么读法；第三层才是当前这份录音实际唱出了什么。现有 Ruby 与 Romaji 同意某种读音，只能证明两份书面层相互吻合，不代表录音已核听。

例如“已”“間”“流離”的特殊读法仍需要固定版本的音证，不能以普通词典音强行覆盖。[[segment:s031]] [[segment:s056]] [[segment:s059]] 反过来，也不应因为某个汉字长得熟悉，就把原作者的特殊表记改成常见写法。

**RED:REPEAT 编辑观察：** 这首歌把难度放在眼睛和耳朵之间：字形给出额外联想，声音要求精准复现，而翻译必须保留真正的句法。把三层分开，才能在理解和学唱时减少“看似懂了，实际唱错或读错”的情况。
