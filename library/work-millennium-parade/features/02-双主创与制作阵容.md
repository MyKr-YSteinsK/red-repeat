# 双主创与制作阵容

《Ｗ●ＲＫ》的公开制作名单解释了它为什么听起来如此拥挤却不松散。官方 MV / 发行资料列出的音乐核心包括：常田大希负责 Music、Guitar 与 All Programming；椎名林檎与常田共同作词、共同演唱；MELRAW 负责 Horn Arrangement 与 Trumpet；宫川纯负责 Organ & Synthesizer，江﨑文武负责 Synthesizer；新井和辉负责 Bass，势喜游负责 Drums。

因此，这首歌并不是“一条 millennium parade 伴奏上请来椎名林檎”。它的词和人声从根部就是双作者结构，而器乐又把常田系制作班底的吉他、铜管、键盘、合成器和节奏组叠在一起。

Real Sound 对声音的分析特别强调了锐利吉他、铜管、键盘色彩与强节奏组之间的叠加。听感上，编曲很少主动给语言让出大片空地；人声必须像另一件打击乐器一样切进轨道。[[segment:s011]] [[segment:s016]] [[segment:s033]] [[segment:s037]]

两位主唱也很少维持一种固定关系：有时像互相下命令，有时像接力，有时像同时逼问同一个对象，后半段则越来越接近对位。[[segment:s041]] [[segment:s046]] [[segment:s056]]

**RED:REPEAT 编辑观察：** “合作感”并不主要来自轮流唱，而来自两套极强的语言与声线被迫在同一个高压节拍里共存。越往后听，越难把谁是主、谁是客分开，这也是它区别于普通 featuring 的地方。
