# 谁在说“我来”，谁又在说“请你”？——《Ｗ●ＲＫ》的发话关系

## 合作署名能确认什么

动画官方音乐资料确认：《Ｗ●ＲＫ》由椎名林檎与常田大希共同作词，常田大希作曲。两位创作者共同负责歌词，不意味着我们能仅凭一个句子的口吻，辨认它是由谁写下或谁唱出。

这篇文章暂不罗列未经完整官方唱片说明核对的器乐演奏名单，也不把歌曲的双人演唱想象成固定的“一个命令、一个服从”。真正可从文字里验证的，是发话者与他者之间不断变化的关系。

## 自我宣告与向外请求

一开始出现的是说话者的主动姿态：要自己报上姓名，也要给出答案。[[segment:s006]] [[segment:s008]] 其中第一句的动词不是要求别人报名字。把它译成“你报上名来”，会使整段的发话方向颠倒。

随后歌曲出现连续的请求句式：请试试积累的技艺，请拿新的腰间佩刀衡量，再借面前的另一个人认识自身的欠缺。[[segment:s017]] [[segment:s018]] [[segment:s020]] 这组动词的共同点，不是单方面压制别人，而是主动让他人的行动成为认识自己的途径。

第一组中另有一句含义尚不能由书面和词典资料锁定的“弾いてくれ”。这里不必为了形成整齐的“三连命令”而提前确定该动词指弹奏、弹开还是其他动作。学习时可先记住它同样含有请求形式，至于动作对象保留疑问。

## 第二组：从能力变成裁断

后一组请求将问题进一步推向过错、判断和关系：请原谅过去所犯，请以新的好坏标准裁断。[[segment:s038]] [[segment:s039]] 紧接着的“如果得救了，就请开导我”仍是条件句，不能写成主人公已经获救；歌词让一种尚未确保的未来进入了请求。[[segment:s040]]

随后“经由所爱之人看到这世界的绝景”将他人的位置再次改变：对方不再只是衡量、评价自己的尺度，也可能成为理解世界的窗口。[[segment:s041]]

**RED:REPEAT 编辑观察：** 前后两组歌词中反复出现的请求形式，能帮助学唱者比较不同动词与发话关系，也能让歌词超出简单的“对手与敌人”关系：自己是谁，既由自己宣告，也会因为被谁衡量、原谅和爱着而重新成为问题。至于实际声部交替与乐器安排，还应在固定音源和正式制作 credits 核验后单独讨论。
