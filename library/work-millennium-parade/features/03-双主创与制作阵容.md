# 双主创与制作阵容

## 先看公开 credits｜Credits First

官方 MV / 发行信息中的音乐 credits 包含：

- Music：Daiki Tsuneta
- Lyrics：Sheena Ringo / Daiki Tsuneta
- Vocals：Sheena Ringo / Daiki Tsuneta
- Guitar & All Programming：Daiki Tsuneta
- Horn Arrangement & Trumpet：MELRAW
- Organ & Synthesizer：Jun Miyakawa
- Synthesizer：Ayatake Ezaki
- Bass：Kazuki Arai
- Drums：Yu Seki

这份名单说明它不是“主唱加一条伴奏”的简单合作：常田大希负责歌曲的核心
制作与吉他/编程，椎名林檎进入词与声部，MELRAW 的铜管、宫川纯与江﨑文武
的合成器，以及新井和辉、势喜游的节奏组共同构成密度很高的表层。

## 为什么听起来既像两个人｜A Shared but Uneven Surface

常田的制作把吉他、编程、铜管与节奏压成强推进的轨道；椎名林檎的语言密度
和声线存在感，则让这条轨道始终带着可辨认的咬字、反讽和人物感。两者不是
简单轮流“各唱一半”，而是在唤醒、命令、请求、赦免和继续前进之间不断改变
关系。[[segment:s011]] [[segment:s016]] [[segment:s037]] [[segment:s038]]

这里的“推进、回应与冲突”是基于编曲与听感的编辑观察，不把某个声部的精确
分配擅自写成官方设定。更值得注意的是：歌曲越靠近后半段，越少给听者留出
把人声、乐器和意义分开的空隙；它让双人合作成为一种结构压力，而不只是客串
名单上的名字。[[segment:s041]] [[segment:s046]] [[segment:s056]]
