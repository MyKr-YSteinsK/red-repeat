# 佛教语汇与“两极之间”

《Ｗ●ＲＫ》使用了几组真正有词典和佛教背景的词，但它们进入歌曲后，不再是安静的概念说明。

`名詮自性` 读作 `みょうせんじしょう`，原本是佛教语，意指名称能够表明事物的性质，也可理解为名与实相应。歌词紧接着谈传闻、完成本愿，后面又出现“报上名字”，让“名字能否说明你是谁”成为一条隐约的轴线。[[segment:s003]]

`煩悩菩提` 是 `煩悩即菩提` 的表达形态。其重点不是“放纵欲望就能开悟”，而是烦恼与菩提并非两个绝对分离的实体。歌曲把它放在“羞耻与欲望一起抱住”后面，正好拒绝了简单的善恶二分。[[segment:s023]]

结尾的 `色即是空` 来自《般若心经》著名语句，强调有形现象并没有固定不变的自性。歌曲随即唱“瞬く間に移ろう”，把哲学词汇直接落到“瞬息迁变”的体验上。[[segment:s060]] [[segment:s061]]

而在进入结尾之前，歌词连续排出弱/强、暗/光、女/男、憎/爱、正确/错误、罪/罚、生/死，最后落到 `両極の間（あわい）`。`あわい` 本来就有两物之间、边界、中间地带的含义。[[segment:s046]] [[segment:s049]] [[segment:s050]] [[segment:s054]] [[segment:s055]] [[segment:s056]]

**RED:REPEAT 编辑观察：** 这首歌最有意思的并不是“选哪一边”，而是把人塞在两极之间继续活。佛教词汇在这里提供的是反二元的语言工具，而不是一套宗教结论。
