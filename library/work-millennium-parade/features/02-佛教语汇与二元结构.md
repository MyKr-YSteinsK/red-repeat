# 佛教语汇与二元结构

## 词语不是教科书｜Terms as Texture

歌词把 `名詮自性`、`煩悩菩提`、`色即是空` 等带有佛教与东亚思想史回声的
词组，放进劳动、肉身和生死压力里。它们在这里首先是高密度的歌词材料：
不是要把歌曲改写成佛学讲义，也不能仅凭几个词就断言作者给出了唯一教义。
[[segment:s003]] [[segment:s023]] [[segment:s060]]

`名詮自性` 可以先作为“名称与本性互相牵引”的文本入口；`煩悩菩提` 则把
烦恼、羞耻、欲望与可能的觉知放在同一个动作里。歌词没有要求先把欲望清空
才获得答案，反而让抱住矛盾本身成为继续行动的条件。这里关于“如何阅读”的
解释是 RED:REPEAT 编辑观察，不冒充创作者的明示意图。

## 二元不是选边｜Duality Without a Clean Side

后半段把弱与强、暗与光、女与男、憎与爱、正确与错误、罪与罚、生与死排成
连续对句。每一对都很短，像判断、反判断和回声；连续出现时，它们不再只是
词典里的反义词，而会变成身体在极端处来回摆动的节拍。[[segment:s046]]

`両極の間` 把这些相反项放回“之间”：不是抹平差异，而是在两极之间承受、
结合，再承担结合后的结果。[[segment:s056]] [[segment:s057]] 这也解释了
为什么歌曲的“极乐/地狱”感不是静态场景，而是随身体、罪罚和欲望不断翻面的
状态。

结尾的 `色即是空` 与 `玉響` 把注意力从永恒判断拉回转瞬即逝的形体和鼓动。
在编辑阅读中，它们让最后的庆贺带着无常感：正因为不能长久，仍在跳动才值得
被听见。[[segment:s060]] [[segment:s061]]
