# 佛教语汇与二元结构

歌词使用“名詮自性”“煩悩菩提”“色即是空”等佛教语汇，但并没有把它们写成安静的讲义，而是置入劳动、肉身与生死压力之中。[[segment:s003]] [[segment:s023]] [[segment:s060]]

“烦恼与菩提”并非简单的坏与好。歌词要求把羞耻和欲望一起抱住，暗示人并不是先清除全部矛盾才获得觉悟，而是在矛盾中认识自身。

后半段把弱与强、暗与光、男女、憎与爱、正确与错误、罪与罚、生与死排成对句。[[segment:s046]] [[segment:s049]] [[segment:s050]] [[segment:s054]] [[segment:s055]]

这些对立最终被放入“両極の間”，也就是两极之间的缝隙。歌曲的结论不是选择一边，而是让相反之物结合并承担其结果。[[segment:s056]] [[segment:s057]]

结尾的“色即是空”与“玉響”共同强调无常：形体、判断和生命都在变化，正因短暂，鼓动才显得值得庆贺。[[segment:s060]] [[segment:s061]]
