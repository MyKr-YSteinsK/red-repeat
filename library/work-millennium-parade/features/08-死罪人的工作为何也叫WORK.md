# 死罪人的“工作”为何也可以读成 WORK

《地狱乐》的故事从一份极端残酷的“任务”开始：被判死刑的人被送往神仙乡寻找不老不死的仙药，成功带回仙药者可以获得无罪放免。画眉丸接受这件事并不是为了建功，而是为了回到妻子身边。官方故事与角色介绍都把“赦免—仙药—生还”写成最初的行动链。

把这个前提放回《Ｗ●ＲＫ》，标题里的 “WORK” 就出现了一层很有《地狱乐》味道的读法。歌词一边写“劳动鼠”“今天也劳动”，一边又写空洞的肉身可以被用完即弃。[[segment:s005]] [[segment:s010]] [[segment:s013]] 这并不能证明歌词是在把幕府直接称作雇主，但“身体被当成执行任务的耗材”与死罪人登岛的处境确实高度同频。

动画第二话甚至把被召集的死罪人先放进“选别”名义下的互相残杀。官方设定里，所谓公仪御免状也只有把仙药带回来的死罪人才能得到。换句话说，这份工作从一开始就没有正常劳动关系里的安全边界：任务、惩罚和生存被绑在同一张契约上。

所以歌词中“社会意义上是凶恶犯？”[[segment:s030]]、请原谅曾经犯下的罪、请用新的善恶来裁判我[[segment:s038]] [[segment:s039]]，放在《地狱乐》里不只是抽象的罪感。故事本身就在不断追问：被判为罪人的人是否只有“罪人”这一种身份？负责斩首的人是否天然站在正确的一侧？

最能把这层阅读收回人物的，还是“还不能死”与“普通生活”。[[segment:s022]] [[segment:s027]] 画眉丸最初被称为“空”的忍者，真正让他拼命求生的却是一个非常普通的愿望：和妻子继续生活。歌曲从可丢弃的身体一路唱到“市井安静的生活”和“所爱之人”，就像把“完成任务”逐渐改写成“为了什么而活”。[[segment:s041]]

Real Sound 当年的乐评也曾把歌曲中的罪、裁判、善恶以及“爱する人”直接联系到《地狱乐》和画眉丸，不过那仍然属于媒体分析，并不是椎名林檎或常田大希公布的逐句注释。

**RED:REPEAT 编辑观察：** 如果把标题理解成双关，《Ｗ●ＲＫ》的“工作”既可以是现代劳动的循环，也可以是死罪人被强加的生存任务。真正重要的不是完成 KPI，而是人物在被当作工具时，仍然为自己找回“想活成谁”的理由。
