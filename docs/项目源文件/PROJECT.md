# 项目合同

RED:REPEAT 帮助使用者反复回到一首歌，查到想练的句子，控制播放范围与速度，听完整首，
再借讲解理解歌词、作品和语境。项目所有者是主要使用者。移动浏览器和已安装 PWA 是优先体验，
桌面浏览器也受支持。项目处于 Production，使用静态前端和本地状态。

## 产品范围

- **曲库**支持搜索、离线筛选、继续上次、待练队列和逐曲下载。待练是用户主动编排的书签式清单。
- **学唱（Practice，默认）**按 Practice Unit 和 Occurrence 定位。用上一段、当前 Segment Picker、
  下一段导航，Picker 独立滚动。单句、连续范围和渐进速度共用歌曲级播放 owner。
- **全曲（Full Song）**按歌词时间线连续播放，支持拖动进度和阅读定位。移动播放器的主操作、
  安全区、可达性、几何和材质属于本模式的体验基线。
- **讲解（Explain）**读取源中明确定义的文章、章节和歌词引用。引用可临时试听。
- **设置与 Timing Debugger**负责版本与更新提示、个人备份、Timing 归档、播放切口调试与导出。
  公开入口是设置中的「播放切口调试」，也可使用 `#timing=debug`。开发专用 Timeline Debugger 单独维护。

保持个人、歌曲优先的定位。账户、云同步、流媒体服务、社交、自动掌握评价和通用语言学习平台
属于需重新决定的产品方向。重大升级方案见[升级审查与路线](升级审查与路线.md)。

## 播放和内容合同

| 概念 | 约束 |
| --- | --- |
| Segment | 可复用的词句和逐句内容。日语原文保留字形、大小写、空格和必要标点。Ruby 是可定位的跨字符注音，译文和 Romaji 各有层。 |
| Occurrence | 一次实际演唱或出现。独立的唯一 `startMs/endMs` 同时驱动解析、高亮和范围播放。 |
| Section | 音乐结构范围。时间与 Occurrence 分开，结构归属允许有效区间跨边界。 |
| Practice Unit | 面向学习的分组，可以与 Section 按不同目标切分。既有 Occurrence ID 有助于兼容恢复。 |
| Song Edition | 一份可验证的歌曲、歌词、Timeline、Practice、讲解及资源快照。即使只改有效 Feature 文本或译文，也可能改变 Edition identity。 |

同曲 Full Song 连播时进入 Explain，默认续播。进入 Practice 浏览保留原播放，明确选择练习才切到
范围播放。切换模式保留各自选择和阅读上下文。Explain 临时试听自然结束时，按试听前的有效位置和
播放意图恢复；用户新操作、取消、退出模式、换歌及错误优先。返回曲库暂停当前歌曲并保留兼容恢复位置。
换歌关闭旧播放操作。全站仅使用一个协调的媒体生命周期，曲库没有全局 mini-player。

## 本机数据和离线合同

- 练习进度、速度、歌词显示、最近会话、待练队列等按各自的浏览器存储和兼容规则维护。个人备份为
  白名单 JSON，先预览再确认，默认保留已有值。数据域覆盖须显式选择。写入异常按键补偿并读回核验。
- 个人 Timing 是同字段的稀疏覆盖。有效 v3 绑定 `songId`、`editionContentHash`、
  `audioSourceHash`、`baseTimelineUrl`。只应用完整身份匹配且通过当前 Occurrence 校验的值。
  非当前版本的有效记录可按原身份保留和单独导出。保全写入并读回前保护旧单槽值，冲突或失败时
  保留可核验旧数据。个人备份与 Timing 历史归档分开。
- 完整离线快照由 manifest、有效 Edition 和精确资源集确定。H1 保持可读，等 H2 的资源及身份通过验证
  才切换 manifest。取消、失败或进程中断后保护最后一个完整版本。缓存里存在几个资源并不代表歌曲已下载。
- PWA 在后台探测和准备，当前文档保持启动时的 build。等待的 worker 在旧客户端自然退出后接管，
  当前会话无更新器主动 reload 或 `SKIP_WAITING` 抢占。部署 build identity 与实际客户端激活分别验证。
